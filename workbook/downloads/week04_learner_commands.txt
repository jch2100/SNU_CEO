# 수강생용 빠른 명령어 카드

## 1. 이야기 시작

```text
시작
```

질문을 고르지 않아도 됩니다. 떠오르는 장면이나 사람부터 자유롭게 말합니다.

## 2. 오늘 대화 정리

```text
중간 정리
```

정리본을 읽고 사실과 표현을 고칩니다.

## 3. 확정본 저장

확인한 정리본 아래의 **프로젝트 소스에 추가**를 누릅니다. 확인 전 초안은 넣지 않습니다.

## 4. 전체 원고 편집

```text
워크 편집 시작
```

여러 확정 자료가 쌓인 뒤에 사용합니다. 장 순서, 중복, 연도, 호칭, 문체를 전체적으로 고칩니다.

## 기억할 한 문장

채팅에서 탐색하고, 소스에서 확정하고, 워크에서 통합합니다.

# 자서전 프로젝트 지침 - 2기 4주차

당신은 자서전을 함께 만드는 따뜻한 인터뷰어이자 편집 보조자입니다. 한국어 존댓말을 사용합니다. 사용자의 사실, 표현, 이야기 순서를 존중합니다.

## 핵심 원칙

- 질문은 기억을 여는 보조 장치다. 사용자의 자유로운 이야기를 언제나 우선한다.
- 한 번에 2~3개의 가벼운 선택지와 “지금 떠오르는 이야기를 자유롭게 말씀해 주세요”를 함께 제시한다.

프로젝트를 만들기 전에

이 워크북 전체 인쇄 PDF만 넣으면 사용법은 알 수 있지만, 실제 2기 교재의 세부 내용까지 충분히 복습하기 어렵습니다.

따라서 프로젝트에는 다음 두 종류를 함께 넣습니다.

  1. 2기 회차별 학습자용 교재·자료팩
  2. 이 워크북의 전체 인쇄 PDF

개인 자서전 원고·회사 내부자료·금융자료는 공통 복습 프로젝트에 넣지 않습니다.

1. 개인 복습 프로젝트 만들기

  1. PC 웹에서 ChatGPT를 엽니다.
  2. 새 프로젝트를 만듭니다.
  3. 프로젝트 이름을 서울대 AI 마스터 졸업생 다시 따라하기 | 2기 기준으로 정합니다.
  4. 개인 프로젝트로 만들고 공유 범위를 확인합니다.

2. 교재 자료를 소스에 넣기

가능하면 아래 순서로 학습자용 자료만 넣습니다.

  1. 00_교재_목차와 사용법
  2. 1회차부터 8회차까지의 학습자용 교재
  3. 프롬프트·체크리스트 보조자료
  4. 워크북 전체 인쇄 PDF

자료 파일 이름에는 회차를 넣습니다. 예: 03_2기_투자판단_학습자용.pdf

3. 전체 인쇄 PDF 만들기

  1. 워크북 우측 하단의 … 도구 버튼을 누릅니다.
  2. 전체 인쇄를 누릅니다.
  3. 인쇄 화면에서 PDF로 저장을 선택합니다.
  4. 파일 이름을 서울대_AI_마스터_다시따라하기_2기.pdf로 저장합니다.

PC에서 저장하는 것을 권장합니다. 모바일에서는 브라우저마다 인쇄 메뉴 이름과 위치가 다를 수 있습니다.

4. 프로젝트 지침에 넣을 내용

다시 따라하기 프로젝트 지침
당신은 서울대 AI 마스터 졸업생을 위한 다시 따라하기 학습 코치입니다.

첨부된 2기 회차별 교재와 자료팩을 가장 우선적인 근거로 사용하세요.
워크북 전체 인쇄 PDF는 목차와 따라하기 순서를 확인하는 보조 자료로 사용하세요.
자료에 없는 내용은 추측하지 말고 [확인 필요]라고 표시하세요.

학습 운영 규칙:
1. 사용자가 특정 회차를 말하면 해당 회차의 교재에서 먼저 읽을 부분을 알려 주세요.
2. 교재를 읽기 전에는 긴 설명을 하지 말고, 읽을 범위와 표시할 것 2개만 안내하세요.
3. 교재를 읽은 뒤에는 강의 순서대로 한 단계씩 진행하세요.
4. 사용자가 완료했다고 말하기 전에는 다음 단계로 넘어가지 마세요.
5. 강의 예시를 먼저 따라 하게 한 뒤, 내 업무나 자료로 바꾸게 하세요.
6. 결과물을 만든 뒤에는 한 가지 수정과 저장을 반드시 안내하세요.
7. 질문·복습·퀴즈는 Chat 모드에 맞게 운영하고, 보고서·슬라이드·30일 계획을 만들 때만 Work 모드를 제안하세요.
8. 투자·자서전·회사자료를 다룰 때는 개인정보·민감정보·사실 확인 주의를 먼저 안내하세요.
9. 최신 기능·화면·정책은 교재의 당시 화면과 다를 수 있으므로 현재 상태 확인이 필요하다고 알려 주세요.

5. 첫 사용법

기본은 Chat 모드입니다. 복습은 대화로 진행하고, 큰 결과물을 만들 때만 Work 모드로 전환합니다. Codex는 이 프로젝트에 사용하지 않습니다.

첫 복습 시작
1회차를 다시 따라 하고 싶습니다.
먼저 1회차 교재에서 읽을 부분과 표시할 것 2개만 알려 주세요.
제가 읽었다고 말하기 전에는 설명이나 다음 단계를 시작하지 마세요.
특정 회차 복습
2기 [회차 또는 주제]를 교재 순서대로 다시 따라 하고 싶습니다.
먼저 해당 교재의 읽을 범위와 오늘 완성할 결과물을 알려 주세요.
그다음 한 단계씩 진행하고, 제가 완료했다고 말하기 전에는 넘어가지 마세요.
결과물 검수
이번 회차에서 만든 결과물을 교재의 완성 기준과 비교해 주세요.
잘된 점, 빠진 점, 사실 확인이 필요한 점을 나누고 가장 먼저 고칠 한 가지만 정해 주세요.

# 회사 문서 스킬 — 직원 설치·사용 가이드 초안

2026.11.04 · 교육용 작성 예시. 실제 회사 패키지와 직원 계정 시험 후 설치 경로·버전·담당자를 확정합니다.

## 담당자가 전달할 것

스킬 또는 플러그인 패키지, 포함된 회사 양식과 작성 기준, 샘플 입력, 버전·변경 내용, 문의 담당자. 실제 실적·고객정보는 패키지에 넣지 않고 매 실행 때 필요한 자료만 받습니다.

## 사용 환경 선택

ChatGPT Work는 작업 방식이며 요금제 이름이 아닙니다. 계정의 Work·스킬·파일 생성 기능과 회사 관리자 설정을 확인합니다. 로컬 방식과 웹 방식 중 담당자가 시험한 방법을 따릅니다.

### 데스크톱 로컬 Work

1. 회사가 전달한 스킬 패키지의 출처와 포함 파일을 확인합니다.
2. 로컬 파일을 다룰 수 있는 환경에서 AI 또는 담당자의 도움으로 사용자용 스킬 위치에 설치합니다. 공식 위치 예시는 `~/.agents/skills/company-document/SKILL.md`입니다. 기존 동명 스킬은 임의로 덮어쓰지 않습니다.
3. ChatGPT 데스크톱 앱의 Skills에서 등록을 확인합니다. 새 Work 대화에서 @를 입력해 목록의 회사 문서 스킬을 선택합니다. 보이지 않으면 설치 위치를 확인하고 앱을 다시 엽니다.
4. 새 자료가 있는 작업 폴더에 접근을 허용합니다. 회사 글꼴이나 생성 도구가 필요하면 담당자의 검증된 설치 안내를 따릅니다.

### 웹 Work

1. 회사 워크스페이스로 로그인하고 Plugins에서 회사가 제공한 문서 플러그인을 찾습니다.
2. 상세 내용을 확인한 뒤 설치 버튼으로 설치합니다. 보이지 않거나 설치할 수 없으면 관리자에게 문의합니다. 회사 관리자가 게시·허용한 뒤에 이용할 수 있습니다.
3. 새 Work 대화에서 @로 플러그인 또는 포함된 스킬을 선택합니다.
4. 새 자료를 첨부합니다. 회사 양식은 패키지에 포함돼 있어야 합니다. 로컬 컴퓨터의 폴더 경로만 입력해도 웹에서 읽을 수 있는 것은 아닙니다.

ZIP을 일반 대화에 첨부하는 것만으로 스킬 설치가 완료되지는 않습니다. 로컬 전용 생성 도구는 웹에서 자동으로 실행되지 않습니다. 담당자가 클라우드에서 시험한 패키지를 사용합니다.

## 처음 요청하기

선택한 회사 문서 스킬로 첨부 자료를 정리해 주세요. 영업 담당자가 다음 달 회의에서 팀장에게 보여줄 문서입니다. 핵심은 고객 문의 변화와 대응입니다. 먼저 부족한 정보를 질문하고 구성안을 보여 주세요. 확인한 뒤 약속한 회사 양식의 파일로 만들어 주세요.

질문에는 받는 사람·목적·기준일·강조할 요지와 필요한 자료를 답합니다. 없는 사실은 모른다고 말하고 표시하도록 요청합니다. 구성안을 확인한 다음 생성을 요청합니다.

## 결과 확인과 수정

- 실제 DOCX 또는 PPTX를 열어 핵심 요지와 숫자·단위·기간을 확인합니다.
- 글꼴·크기·위치, 표, 글자 잘림과 겹침을 확인합니다. 웹에서는 파일을 내려받아 확인합니다.
- “2쪽 표의 마지막 열이 잘립니다. 기준을 확인하고 새 버전으로 저장해 주세요”처럼 문제 위치와 원하는 결과를 말합니다.
- 원본과 이전 결과는 보존합니다. 외부 발송은 별도로 확인합니다.

## 막히면

스킬 이름과 버전, 사용 환경, 오류 문구, 기대한 결과와 실제 결과를 담당자에게 전달합니다. 비밀번호·인증키는 보내지 않습니다. 업데이트한 스킬은 다시 설치하거나 회사의 갱신 안내에 따라 새 대화에서 확인합니다.

## 담당자의 배포 전 시험

별도 직원 계정에서 설치 → 새 대화에서 호출 → 새 자료 입력 → 질문과 구성안 확인 → 실제 파일 생성 → 열기·수정까지 확인합니다. 설치만 확인한 경우 전체 사용 완료로 기록하지 않습니다.

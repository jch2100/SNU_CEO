02 · 앱 설치와 로그인

ChatGPT 데스크톱 앱을 설치하고,
Codex를 열어 주세요.

1. 공식 한국어 다운로드 페이지를 엽니다.

페이지 상단의 ChatGPT 데스크톱 다운로드 영역에서 본인 컴퓨터에 맞는 앱을 받습니다. Windows에서는 Windows용 다운로드, Mac에서는 Mac용 다운로드를 선택해 주세요. 페이지 아래의 ChatGPT Classic은 이번 수업용 설치 대상이 아닙니다.

ChatGPT 데스크톱 다운로드 ↗
Mac에서 다운로드 종류를 고르기 어렵다면

공식 시작 안내에서 다운로드 버튼 옆 메뉴를 열면 macOS (Apple silicon)과 macOS (Intel)을 선택할 수 있습니다. 자신의 Mac 종류를 모르겠다면 현장에서 도움을 받아 주세요.

2. 설치한 앱을 열고 본인 계정으로 로그인합니다.

기존 ChatGPT 계정을 사용하면 됩니다. Codex용 계정을 따로 만들 필요는 없습니다.

3. 앱 왼쪽 상단에서 Codex를 선택하고 ‘새 채팅’을 누릅니다.

왼쪽 상단에 이미 Codex라고 보이면 그대로 진행합니다. 이번 Python 준비는 프로젝트를 만들거나 폴더를 연결하지 않고 시작합니다.

03 · Codex에 Python 설치 요청

프로젝트는 선택하지 않고,
‘이 컴퓨터’에서 요청합니다.

1. ‘프로젝트 선택’은 그대로 둡니다.

입력창 위에 프로젝트 선택이라고 보이면 아직 프로젝트를 선택하지 않은 상태입니다. 이 버튼을 눌러 프로젝트를 만들 필요가 없습니다. C드라이브나 문서 폴더도 선택하지 않습니다.

이미 다른 프로젝트 이름이 보인다면

입력창 위의 프로젝트 이름을 누르고 프로젝트 없이 작업하기를 선택합니다. 메뉴 표현이나 화면이 다르면 새 채팅을 열어 확인해 주세요. 찾기 어렵다면 현장에서 함께 확인합니다.

2. 옆에 ‘이 컴퓨터’가 표시되는지 확인합니다.

클라우드가 보이면 작업 위치 메뉴를 눌러 이 컴퓨터로 바꿉니다. Python을 준비할 곳은 수업에 가져올 본인 노트북입니다.

3. 아래 요청을 복사해 입력창에 붙여넣고 전송합니다.

상자 오른쪽 위의 복사 버튼을 누릅니다. 앱 아래쪽 무엇이든 요청하세요 입력창을 누르고 붙여넣습니다. Windows는 Ctrl+V, Mac은 ⌘+V를 사용합니다. 내용을 확인한 뒤 전송 버튼을 누릅니다.

이 컴퓨터에서 Python을 사용할 수 있는지 먼저 확인해 주세요.
이미 사용할 수 있다면 기존 설치를 사용해 주세요.
없다면 내 운영체제에 맞는 정식 Python을 공식 경로로 설치해 주세요.

내가 눌러야 하는 설치·승인 화면이 나오면 한 단계씩 알려 주세요.
마지막으로 간단한 Python 코드를 실제 실행해서
성공 여부와 사용한 버전·실행 경로를 알려 주세요.

4. 안내를 따라 설치하고 실행 결과를 확인합니다.

Codex가 확인하거나 설치하는 동안 기다립니다. 설치·승인 화면이 나오면 어떤 작업인지 읽고 안내에 따라 진행합니다. 완료 후에는 Python 버전과 실제 코드 실행 성공 여부를 확인합니다. 회사 노트북의 설치 제한 등으로 막히면 오류 화면을 남기고 현장에서 도움을 받아 주세요.

완료 기준: 다운로드만 한 상태가 아니라, Codex가 Python 코드를 실제로 실행하고 성공했다고 알려 준 상태입니다.

업계·경쟁사 정보를 모아 직원과 공유하는 대시보드, 자료 분석에 근거한 사업계획서, 계속 개선되는 직무 안내서, 고객 접수부터 문서 작성까지 이어지는 업무 도구를 만들어 봅니다.

Codex와 ChatGPT Sites를 활용해 자신의 업무와 아이디어를 구체화합니다. 코딩 문법보다 업무의 맥락을 설명하고, 결과를 확인하고, 필요한 수정을 요청하는 경험에 집중합니다.

참여자의 사전 설문, 학습 수준, 실습 진행 상황에 따라 세부 내용과 순서는 조정될 수 있습니다.
02 · 8주 과정

정보를 모으는 일에서,
우리 회사 과제를 실행하는 일까지.

01

환경 이해와 실습, 그리고 기획

AI가 어디서 어떻게 일하는지 이해하고, 작은 요청부터 시작합니다.

Codex 데스크톱의 화면과 작업 폴더, 모델 선택, 작업 위치, 플러그인·스킬·설정의 역할을 살펴봅니다. 간단한 결과물을 요청하고 직접 확인·수정한 뒤, 자신의 업무와 아이디어를 대화로 구체화합니다.

실습 결과: 직접 수정한 작은 결과물과 개인 과제 후보.

02

리서치 자동화와 직원 공유 대시보드

우리 업계와 경쟁사의 정보를 모아, 직원이 함께 보는 페이지로 만듭니다.

조사할 질문과 출처, 비교 기준을 정하고 필요한 정보를 수집·정리합니다. ChatGPT Sites로 출처·날짜·핵심 내용·변화가 보이는 대시보드를 만들고 링크로 공유합니다. 반복해서 활용할 조사 기준과 결과 정리 방식을 함께 설계합니다.

실습 결과: 업계·경쟁사 조사 기준과 공유용 리서치 대시보드.

03

자료 분석과 사업계획서 — 문서 자동화

조사 결과와 숫자를 근거 있는 계획으로 바꿉니다.

시장·경쟁정보와 매출·비용 자료를 분석해 사업계획서, 서비스 개선계획서 또는 업무 개선계획서를 작성합니다. 근거 자료와 가정을 구분하고, 입력 조건을 바꾸어 계산·표·문서가 함께 갱신되는 과정을 실습합니다.

실습 결과: 분석 근거와 실행계획을 갖춘 문서, 반복 작성에 활용할 기준.

04

회사 자료를 어디까지 맡기고 공유할까?

만든 결과를 보안·공유·실행 범위의 관점에서 점검하고 고칩니다.

앞선 실습 결과를 활용해 AI에 제공할 자료를 선별하고 민감한 항목을 가리는 연습을 합니다. 링크의 공유 범위, 파일 변경 전 확인, 잘못된 변경의 복원, 외부 게시·전송 전에 확인할 사항을 직접 점검합니다. 개인 결과물의 오류와 막힌 부분도 함께 보완합니다.

실습 결과: 점검·수정한 결과물과 자신의 업무에 적용할 자료·공유·실행 기준.

05

외부 홈페이지 제작과 Google·네이버 검색 등록

우리 회사와 서비스를 설명하는 페이지를 만들고 검색 등록을 진행합니다.

고객에게 필요한 정보와 서비스의 차별점을 정리해 ChatGPT Sites로 외부 홈페이지를 제작합니다. Google Search Console과 네이버 서치어드바이저의 사이트 등록·소유확인·수집 요청 절차를 실습하고, 이후 검색 반영 상태를 확인하는 방법을 익힙니다.

실습 결과: 서비스 소개 홈페이지와 검색 등록·진단 실습 기록.

검색 등록 실습은 소유확인이 가능한 사이트를 기준으로 진행합니다. 검색 반영 시점과 노출 순위는 검색엔진에 따라 달라집니다.

06

업무 폴더 시스템화와 계속 개선되는 직무 안내서

한 업무의 자료와 처리 기준을 정리해, 다른 직원도 이어서 일할 수 있게 만듭니다.

업무 폴더의 목적, 필요한 자료, 처리 순서, 결과와 확인 기준을 정합니다. 폴더와 파일을 정리하고 작업표준·직무 안내서를 작성합니다. 새 자료와 직원 질문을 반영해 안내서가 개선되는 과정까지 실습합니다.

실습 결과: 한 업무의 정리된 폴더와 갱신 가능한 작업표준·직무 안내서.

07

접수·처리·문서·회답을 연결하는 업무 자동화

문자·사진·발주 자료를 실제 처리 흐름으로 연결합니다.

고객이 보낸 정보를 확인표와 대장으로 정리하고, 처리 상태를 관리하며 문서와 회답 초안으로 이어지게 만듭니다. 상담·견적·발주 등 자신의 업무에 맞게 입력 항목과 처리 기준을 조정합니다.

실습 결과: 접수 자료에서 처리 현황과 문서·회답 초안까지 이어지는 작은 업무 도구.

08

실무 해커톤 — 우리 회사 과제, 현장에서 실행하기

회사에서 해결하고 싶은 과제를 가져와, 현장에서 만들고 실행합니다.

업무 과제와 실습 가능한 자료를 바탕으로 강사·조교와 당일 실행 범위를 정합니다. 앞서 익힌 리서치, 문서 자동화, 웹페이지, 폴더 시스템화, 접수·처리 방식을 활용해 작동하는 결과를 만들고 확인·수정합니다. 결과를 시연하고 피드백을 나누며 다음 개선 계획과 수료로 마무리합니다.

실습 결과: 현장에서 실행·확인한 결과물과 다음 개선 계획.

공통 실습을 경험하고, 자신의 업무에 필요한 결과물을 선택해 발전시킵니다. 과제의 규모보다 실제로 실행해 보고, 결과를 확인하고, 다음에도 다시 쓸 수 있는 기준을 남기는 것을 중요하게 다룹니다.

환경 이해

02

작은 요청과 수정

수업용 폴더에서 간단한 일을 요청하고, 결과 위치를 찾아 직접 확인한 뒤 한 가지를 수정해 봅니다.

03

대화로 시작하는 기획

생각을 자유롭게 말하고 AI가 부족한 점을 질문하게 합니다. 답하고 조정하면서 무엇이 불편한지, 누구를 위한 것인지, 어디까지 해볼지를 정리합니다.

첫날부터 완성된 기획서를 요구하지 않습니다. 자신의 업무 후보와 더 확인할 점을 찾고, 강사·조교의 도움으로 첫 범위를 좁혀 갑니다.
